- **정량평가 항목별 산출근거를 확인**하고 평가결과와 제출자료 간 **정합성을 크로스체크** — 오류·누락 발견 시 공유 및 수정 지원
- 컨소시엄 구성, 참여사 간 지분·역할 관계 정리 및 사업 분담비율 검토

> 실제 투자심사 위원회가 사업을 검토하는 과정을 가장 가까이서 지켜보고 보조하며, **재무지표 해석 → 정합성 검증 → 심사자료 구조화**로 이어지는 심사 실무의 흐름을 체득했습니다.

## 💬 지원 동기 & 포부

KIND 인턴으로 재무지표를 해석하고 제출자료의 정합성을 검증하며, 하나의 사업이 심사대에 오르기까지 **얼마나 많은 교차검증과 근거자료가 필요한지** 직접 경험했습니다.

카카오맵 API 전환 사례처럼, 주어진 데이터·자료를 그대로 받아들이지 않고 **오류 가능성을 의심하고 검증하는 태도**를 심사 업무에서 가장 중요한 자질이라고 생각합니다.

한화 투자심사 직무에서 재무·산업 분석 역량을 더 깊이 쌓으며, 숫자 이면의 리스크까지 짚어낼 수 있는 **신뢰받는 심사역**으로 성장하고 싶습니다.
